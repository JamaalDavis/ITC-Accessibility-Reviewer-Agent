DOCUMENTATION / GETTING STARTED

Inclusion is a practice.

A small, inspectable foundation for your next product.

What’s in v0

Nine semantic color tokens in three themes, a token JSON export, two simulated AI interactions, and a locally saved manual audit checklist. The existing accessibility review engine remains available through the repository’s review commands.

Use the foundation

  1. Explore the tokens and switch themes to inspect contrast pairs.
  2. Export the active theme as a JSON token file with primitive, semantic, and component layers.
  3. Test the components with a keyboard and your screen reader.
  4. Record observations and export the checklist with your evidence.

Standards & boundaries

The token export uses the DTCG 2025.10 format, including structured sRGB values and aliases. Themes export as separate files; OS forced colors are handled by CSS system colors.

Contrast calculations follow WCAG relative luminance for opaque sRGB pairs. A passing pair does not establish page or product conformance. Manual verification is still required for screen reader behavior, zoom, reading order, focus, and real content.

Next beyond the MVP

Live model and speech integrations, Figma library synchronization, CI coverage across component states, and an evidence-backed ACR are future work. This prototype does not generate certification claims.
